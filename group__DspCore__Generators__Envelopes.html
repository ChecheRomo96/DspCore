Detailed Description

Linear, exponential, logarithmic and optional LUT-shaped segments.

Ranges are half-open [first,last), with last defaulting to total. Unlike legacy code, last>total is rejected instead of clamped. Empty valid ranges write nothing. Singletons write start. Longer segments include exact start and end. Exponential shape=(1-exp(-curve*t))/(1-exp(-curve)); logarithmic shape=log(1+curve*t)/log(1+curve). Nonnegative curve zero has a linear limit; curves <= 8*epsilon also use that limit to avoid underflow/cancellation.

LUTSegment is available when both LUT and Interpolation are enabled. Shape samples must be finite in [0,1]. Tables of size >=2 must have exact zero/one endpoints; intermediate samples need not be monotonic. A singleton shape maps start+(end-start)*shape[0] across the entire segment, except a singleton segment always writes start. This is an intentional constant-shape exception to the usual endpoint rule. Empty/invalid tables fail. The entire claimed output buffer must be disjoint from the logical shape storage; overlap is rejected before writing. Table validation precedes output and does not allocate. Output is written only within [first,last). Examples: Generators/Envelopes and Generators/LUTEnvelope.
