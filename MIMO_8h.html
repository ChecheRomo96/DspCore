Detailed Description

Reserved home for multiple-input multiple-output linear filters.

Status
Planned; this header intentionally declares no MIMO processor yet.

A MIMO FIR has a matrix of taps for every delay. A MIMO recursive filter is usually clearer as a state-space realization with matrices . That future API will define channel/frame layout and fixed-size or caller-supplied matrix storage. It will not introduce stream routing, heterogeneous ports, FIFOs, or scheduling into DspCore.
