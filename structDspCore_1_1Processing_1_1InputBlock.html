Detailed Description

template<typename Real>
struct DspCore::Processing::InputBlock< Real >

A non-owning input signal block.

A zero-length block may use a null data pointer. A nonempty block requires readable storage for exactly size values. The processor never writes through this view and never retains the pointer after ProcessorBase::Process returns.
