Detailed Description

Sine, saw, square and triangle cycles without a duplicate endpoint.

Phase is in cycles, wraps negative/large finite values into [0,1), and is computed from the sample index rather than accumulated. A singleton samples the supplied phase. Output is offset + amplitude * waveform(phase+i/N).

Wave Phase zero Quarter-cycle Half-cycle Three-quarter-cycle
Sine 0 1 0 -1
Saw 0 0.5 -1 -0.5
Square 1 1 -1 -1
Triangle 0 1 0 -1

These conventions preserve the historical saw/triangle phase offsets. The tables are naive and not band-limited. They are not streaming oscillators with a sample rate or anti-aliasing. Use periodic lookup with Boundary::Wrap for tables without duplicated endpoints. Example: Generators/Periodic.
