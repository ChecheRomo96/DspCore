Detailed Description

Reproducible xorshift32 sequence with explicit caller-owned state.

White requires a nonzero uint32_t state reference. Zero is rejected because it is an absorbing state of xorshift32. No default seed is restarted on each call. Reuse the updated state for continuity across arbitrary block sizes. Output is offset + amplitude*(2*state/UINT32_MAX-1), nominally in offset+[-amplitude,amplitude]. Floating rounding can reach endpoints. This is deterministic pseudorandom signal generation, not cryptography. An empty call leaves a valid state unchanged. Example: Generators/Noise.
