Detailed Description

template<typename SampleType>
struct DspCore::Processing::SampleBlock< SampleType >

Non-owning typed view of a fixed-size contiguous sample region.

SampleBlock only describes caller-owned memory; it never allocates, copies, frees, queues, schedules, or resamples samples. SampleBlock<const T> is a read-only input view and SampleBlock<T> is writable output storage. The same template therefore expresses the access contract directly in C++.

Its size is the complete extent of the view. DspCore's n-to-n algorithms require their input and output blocks to have equal sizes, so there is no separate capacity, produced-count, commit operation, or hidden buffering. The caller keeps both the view and the backing samples alive for the whole Process call.
