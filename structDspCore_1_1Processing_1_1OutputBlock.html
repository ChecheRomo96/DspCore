Detailed Description

template<typename Real>
struct DspCore::Processing::OutputBlock< Real >

A caller-owned output signal block.

capacity is the writable capacity supplied by the caller. On return, a processor sets size to the number of valid output values it wrote. A processor must call CanWrite before writing and must not exceed capacity. It never frees, reallocates or retains data.
