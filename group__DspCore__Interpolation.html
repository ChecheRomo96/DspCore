Detailed Description

Float/double linear, bilinear and trilinear interpolation arithmetic.

Include <DspCore_Interpolation.h> or <DspCore/Interpolation/Arithmetic.h>. No operation allocates, throws, or owns/modifies table storage.

Arithmetic

NormalizedLinear(value0,value1,t) evaluates a line with normalized t; NormalizedBilinear and NormalizedTrilinear compose it on independent normalized axes. Values outside [0,1] extrapolate. No boundary policy is hidden in the formulas. Use consistent float or double arguments (or an explicit template argument); integer-only arithmetic is rejected at compile time. Double computations are never reduced to float.

Corner order is x-fast, matching LUT storage:

  • Bilinear: f00, f10, f01, f11, x, y.
  • Trilinear: f000, f100, f010, f110, f001, f101, f011, f111, x, y, z.

f(x,y) = L(L(f00,f10,x), L(f01,f11,x), y)

Linear returns exact endpoints at t=0 and t=1 and uses a weighted form for opposite-sign endpoints to avoid overflowing their difference during interpolation. NaN/Inf samples may propagate; extrapolation may overflow. Results are not clipped. Exact endpoints select the corresponding sample even if an unused sample is non-finite.

Physical coordinates

LinearAt/BilinearAt/TrilinearAt accept physical coordinates and normalize each axis before applying the corresponding normalized formula. Endpoint names use 0/1 rather than min/max because a descending axis is valid: x1 may be smaller than x0. A collapsed axis (x0==x1) produces normalized coordinate zero, selecting its 0-side without dividing by zero. Extrapolation is permitted. Non-finite arithmetic follows normal floating point propagation; these mathematical functions do not return a bool. For a non-collapsed physical axis, its normalized coordinate is

When , DspCore deliberately defines ; this selects the 0-side and makes descending or degenerate axes explicit rather than treating their endpoint names as min/max.

// Physical x=15 over x0=10, x1=20, with values 2 and 8: value=5.
double value = DspCore::Interpolation::LinearAt(10.,20.,2.,8.,15.);
