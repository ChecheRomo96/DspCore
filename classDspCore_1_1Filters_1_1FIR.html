Processes sampleCount input values into equally sized output storage.

Both pointers may be null only for a zero-length block. On success every output value is valid. Invalid views or non-finite input leave state and output unchanged. A finite arithmetic failure may commit an output prefix before returning false.

Restores the processor to its documented initial signal state.
