Foundation source dependency contract.

DspCore links Foundation::Foundation publicly. Its pinned source baseline is Foundation 0.0.1, which brings CPSTL 0.0.1 with it.

For a source build, cmake/DspCoreFoundation.cmake first reuses a Foundation::Foundation target supplied by the parent project. Otherwise, with DSPCORE_FETCH_FOUNDATION enabled (the default), it obtains the Foundation sources at tag v0.0.1 with FetchContent and builds them with DspCore's toolchain.

FETCHCONTENT_SOURCE_DIR_FOUNDATION substitutes a local Foundation working copy for the download. Set DSPCORE_FETCH_FOUNDATION=OFF only when the parent project already provides Foundation::Foundation.

An exported DspCore Release package is a separate distribution workflow. Its DspCoreConfig.cmake uses find_dependency(Foundation) when a downstream project consumes the package.
