Detailed Description

Allocation-free table and segment generation into caller-owned buffers.

Include <DspCore_Generators.h> or an individual family header under <DspCore/Generators/>. All arithmetic and output use a consistent float or double type. No generator allocates, resizes a LUT, clips PCM, throws, or changes global floating-point mode. Integer output/conversion is deferred.

Buffers and failure

Functions return bool. Invalid parameters, nonempty null buffers, byte-count overflow, or invalid ranges return false before writing output or advancing noise state. The caller guarantees the stated accessible buffer extent; raw pointers cannot verify its actual allocation. A null pointer is allowed for zero count, with valid parameters. Empty ranges write nothing.

Amplitudes/scales must be finite and nonnegative. Parameters and endpoints must be finite. Periodic/noise generators additionally require offset +/- amplitude to remain finite. Shape drive/gamma/gain must be strictly positive; envelope curve may be zero. Invalid domains are rejected, never silently replaced by arbitrary minimum drive or curve values.

Using LUT storage

Generators operate on contiguous public storage, independently of ownership or dimensions. Allocate beforehand, then pass GetBuffer and Size for a 1D table, or a row/slice pointer and width for higher dimensions. Changing parameters between rows/slices builds a 2D/3D family of curves. This replaces the historical virtual LUT3D::Eval and dimension-specific generator wrappers.

DspCore::LUT::LUT3D<float> curves;
if (!curves.Resize(5,2,2)) { return; }
for (size_t z=0; z<2; ++z) {
for (size_t y=0; y<2; ++y) {
bool ok = DspCore::Generators::Shaping::GammaMorph(
curves.GetBuffer()+(z*2+y)*5, 5,
static_cast<float>(y), static_cast<float>(z+1));
}
}

Numerical behavior

Float calls use float math functions; double calls use double functions. No platform-dependent public type substitution occurs; AVR double may have the same precision as float. Stable small-argument series avoid the exp/log cancellation defects in the legacy envelopes without depending on expm1/log1p availability in AVR libc. Normalized shape roundoff is bounded to its mathematical range; no general signal saturation is introduced. Huge counts may exceed coordinate resolution; no uniqueness/throughput guarantee is made beyond the selected arithmetic type's precision.
