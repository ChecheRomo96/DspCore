Detailed Description

Single-rate FIR/IIR filters, coefficient designers, and future filter families.

FIR<SampleType, CoefficientType, StateType> and IIR<SampleType, CoefficientType, StateType> own their coefficient and delay storage. SampleType is the external stream type; CoefficientType defaults to float and StateType defaults to CoefficientType. Configure may resize storage outside the processing path; Process never allocates. Both accept direct, caller-owned Processing::SampleBlock<const SampleType> input and Processing::SampleBlock<SampleType> output views with the same fixed extent. Biquad functions are stateless coefficient designers: each returns a coefficient value accepted by IIR::Configure. Use Biquad::Design<CoefficientType> to choose coefficient precision explicitly; it defaults to float. Biquad::ParameterCount(Type), Biquad::ParameterAt(Type, cpstd::size_t, ParameterInfo&) and Biquad::HasParameter(Type, Parameter) expose allocation-free metadata for controls required by each design. The metadata remains in program memory on AVR and is copied into a caller-owned value on access.

The implemented processors are under Single-rate filters. SOS.h, Multirate.h, and MIMO.h establish future module boundaries; they deliberately declare no incomplete runtime API.
