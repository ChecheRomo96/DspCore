Read the library and Foundation version metadata compiled into an application.

Goal

Confirm the exact DspCore and Foundation releases seen by an application. This is the smallest possible integration check before using a larger API.

Run

./build/macos_arm64/bin/Debug/DspCore_Core_Version_d

Output

DspCore :: Core / Version
DspCore ....... 0.2.0
Foundation .... 2.0.8

The values identify the headers selected by the build, rather than a runtime package discovered by the executable.
