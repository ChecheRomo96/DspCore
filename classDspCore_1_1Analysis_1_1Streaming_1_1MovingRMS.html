Detailed Description

template<typename Real = float>
class DspCore::Analysis::Streaming::MovingRMS< Real >

Exact moving RMS with one result per sample and a fixed sample window.

Configure allocates the history once. Update reuses its running sum and ring slot, so it performs constant work and no allocation. Before the ring is full, output uses the available sample count; IsReady reports when the configured window is complete.
