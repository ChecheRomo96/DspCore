Detailed Description

Free functions returning six-coefficient second-order descriptions.

Namespace DspCore::Filters::Biquad contains Coefficients<T>, LowPass, HighPass and IsStable. There is no Biquad processing class or Design namespace. Coefficients<T> contains only numerator[3] (b0,b1,b2) and denominator[3] (a0,a1,a2), with identity defaults. It is trivially copyable and occupies six scalars. One value can configure independent IIR instances.

LowPass(sampleRate,cutoff,Q) and HighPass(...) return this struct by value, including raw a0; IIR performs normalization. Require finite positive sample rate/Q and 0<cutoff<sampleRate/2. Invalid or numerically unrepresentable designs return denominator[0]==0 so IIR::Configure rejects them, preserving its previous configuration/history. No exception or hidden identity fallback.

Calculations follow the W3C Audio EQ Cookbook (Robert Bristow-Johnson), with half-angle numerator identities. IsStable validates finite/normalizable coefficients and strict normalized pole bounds: -1
